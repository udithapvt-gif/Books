    📱 Open on Phone or Other Computers

    When the database server is running on this computer, any smartphone, tablet, or laptop on the same Wi-Fi network can log in and view live books instantly at:

    http://<your-local-ip>:3000

    How to run the Central Database Server:

    Open terminal or PowerShell in this folder and run:

    node server.js

    Works with zero installations! The database file is stored safely at data/library_database.json.

    If you deploy server.js to Render, Railway, or Glitch, enter your live URL here to access it from anywhere in the world.
